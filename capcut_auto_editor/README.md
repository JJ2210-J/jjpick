# 캡컷 자동 편집기

롱폼 영상 한 편을 캡컷에서 편집할 때의 반복 작업을 줄여 주는 로컬 도구입니다.
브라우저에서 열리는 화면으로 쓰지만 **전부 내 컴퓨터 안에서만 돕니다.**
외부 AI API를 부르지 않고, 영상을 어디에도 올리지 않습니다.

무엇을 해 주냐면:

- 무음·필러워드("어", "그러니까 이제")·말더듬을 찾아 **컷 후보**를 만들어 줍니다 (자동으로 잘라내지 않습니다)
- 음성을 받아적고 대본과 맞춰 **한 줄 자막**을 만들어 캡컷 드래프트에 넣습니다
- 이미지 클립 앞뒤에 **트랜지션**과 **효과음**을 배치합니다
- 유튜브 제목·설명글·해시태그용 **프롬프트**를 조립해 줍니다 (문구 자체는 원하는 AI에 붙여넣어 받으세요)
- 20~30초 **세로 영상(쇼츠·릴스)** 드래프트를 만들어 줍니다

---

## 1. 설치

### 준비물

| 항목 | 버전 | 확인 방법 |
|---|---|---|
| Windows | 11 | |
| Python | **3.11** | `python --version` |
| ffmpeg | Gyan.FFmpeg 9.0 | `ffmpeg -version` |
| 캡컷 | 9.3.0.3969 (beta) 에서 검증 | 캡컷 → 설정 |

Python 3.12 이상은 **검증하지 않았습니다.** 3.11을 쓰세요.
설치할 때 **"Add Python to PATH"를 반드시 체크**해야 합니다.

ffmpeg이 없으면:

```
winget install Gyan.FFmpeg
```

설치 후 **새 터미널 창을 열어야** 인식됩니다.

### 설치하기

`처음 한 번 설치.bat` 을 더블클릭하세요. 아래를 대신 해 줍니다.

```
python -m pip install -r requirements.txt
```

torch는 쓰지 않습니다. faster-whisper가 CTranslate2와 onnxruntime으로 돌기 때문에
약 2.5GB를 아낍니다.

## 2. 실행

`캡컷 자동 편집기 실행.bat` 을 더블클릭하면 서버가 뜨고 브라우저가 열립니다.
터미널에서 직접 띄우려면:

```
python run.py
```

주소는 `http://127.0.0.1:8733` 입니다. 이미 쓰는 포트면 8734, 8735… 로 알아서 옮겨 갑니다.
검은 창을 닫으면 서버가 꺼집니다.

## 3. 작업 순서

영상 한 편 = 한 세션입니다. 상태가 저장되므로 브라우저를 껐다 켜도 이어서 할 수 있습니다.

### 0차 프로젝트 준비

원본 영상을 순서대로 고릅니다. 여러 개를 골라도 **하나로 이어붙인 타임라인**으로 다룹니다.
경로를 넣는 방법이 세 가지입니다.

1. 앱에서 찾아보기 (마지막에 쓴 폴더에서 시작합니다)
2. 윈도우 기본 선택 창 (여러 개 선택 가능)
3. 경로 직접 붙여넣기 (**폴더 경로를 넣으면 그 안의 영상을 모두 불러옵니다**)

경로에 오타가 있으면 어디까지가 맞는 경로인지 알려 줍니다.
해상도나 프레임레이트가 섞이면 경고하지만 막지는 않습니다. 캔버스는 가장 큰 해상도 기준입니다.

### 자막 스타일 캘리브레이션 ← **1차보다 먼저 하세요**

캡컷에서 자막을 넣어 만든 프로젝트를 하나 고르면 글꼴·크기·색·배경·위치를 그대로 가져옵니다.

이 단계를 건너뛰면 **2차 자막이 캡컷 화면에 제대로 안 보입니다.**
pyCapCut이 만드는 자막 소재는 필드가 20개뿐이라 캡컷이 채우는 값 대부분이 비어 있기 때문입니다.
그래서 빈 껍데기에 스타일을 얹지 않고, 캡컷 원본 소재를 통째로 복제해 텍스트만 갈아끼웁니다.

같은 화면에서 **트랜지션도 함께 가져옵니다.** 캡컷에서 원하는 트랜지션을 한 번 적용해 두면
그 `effect_id`를 읽어 정확히 찾아옵니다. (이름으로는 못 찾습니다. 2절 참고)

캡컷을 쓸 수 없으면 수동 입력도 되지만, 화면에는 **추정값**이라고 표시됩니다.

### 1차 컷 편집

슬라이더 네 개가 있습니다.

| 값 | 기본 | 뜻 |
|---|---|---|
| 무음 임계값 | -35dB | 이보다 조용하면 무음 |
| 최소 무음 길이 | 0.6초 | 이보다 짧은 무음은 무시 |
| **말 끝난 뒤 여유** | **0.35초** | 무음 시작 쪽에 남길 여유 |
| **다음 말 시작 전 여유** | **0.15초** | 무음 끝 쪽에 남길 여유 |

앞뒤 여유가 왜 다르냐면, 무음 감지는 소리가 임계값 **아래로 떨어진 뒤**를 무음 시작으로 보는데
말끝의 자음과 여운은 이미 그 아래에 있기 때문입니다. 꼬리 여유가 짧으면 마지막 음절이 잘려 들립니다.
그래서 하나의 값으로 처리하지 않고 따로 둡니다.

> 최소 무음 길이를 너무 공격적으로 잡지 마세요. 문장 사이 자연스러운 호흡까지 잘리면
> 듣기 부자연스러워집니다.

컷 후보는 세 종류(무음 / 필러 / 반복)로 나오고 **기본으로 전부 체크돼 있습니다.**
반드시 검수하세요. 잘리는 비율이 40%를 넘으면 경고하고, "긴 무음(3초 이상) 살리기" 버튼을 줍니다.
화면만 보여주며 말을 안 하는 시연 구간이 통째로 날아가는 걸 막기 위한 것입니다.

검수가 끝나면 드래프트를 만듭니다. **이때의 컷 설정이 기록됩니다.** (아래 2차 참고)

### 2차 자막 생성

대본 파일(txt/srt/md)이 있으면 올리세요. 음성 인식 결과와 맞춰서
**성립하는 구간은 대본을 정본으로, 타임코드는 음성 인식에서** 가져옵니다.
대본에 없는 즉흥 발화는 음성 인식 결과를 그대로 씁니다.
대본이 없으면 음성 인식만 쓰되 신뢰도가 낮은 구간을 표시해 줍니다.

자막 규칙:

- **항상 한 줄**입니다
- 문장 끝(`. ! ? …`)과 구절(`, · ; :`)에서 끊고, 부호는 앞 조각에 붙입니다
- 한 줄 36자가 기본 상한입니다
- 상한을 넘으면 어절 단위로 **고르게** 나눕니다 (앞에서부터 꽉 채우면 짧은 꼬리가 생겨
  화면을 스쳐 지나갑니다)
- 한글은 어절, 영문도 단어 단위로만 끊습니다. 하이픈으로 자르지 않습니다
- 물류·AI 영어 용어는 원문 표기를 유지합니다 (설정에서 항목별로 켜고 끌 수 있습니다)
- **컷에서 잘려나간 단어는 자막에서도 뺍니다.** 컷은 시간만 지우기 때문에,
  이 처리를 안 하면 방금 잘라낸 "그 그 그"가 자막에 그대로 뜹니다

> **드래프트를 만든 뒤 컷 선택을 바꾸면 자막 생성이 차단됩니다.**
> 자막 시각은 "지금 컷 설정" 기준인데 드래프트는 "만들 당시 컷 설정"이라,
> 그대로 넣으면 앞부분만 맞고 뒤로 갈수록 벌어집니다.
> 1차에서 드래프트를 다시 만들거나 컷 선택을 되돌리세요.

검수 테이블에서 자막을 직접 고칠 수 있고, SRT로 내보낼 수 있습니다.

### 3차 트랜지션 및 효과음

드래프트에서 이미지 클립을 찾아 앞/뒤 트랜지션을 체크박스로 고릅니다.
트랜지션은 pyCapCut 규칙상 **앞쪽 세그먼트에 붙습니다.**
효과음은 `assets/sfx/` 폴더에 wav를 넣어 두면 목록에 나옵니다.

### 4차 내보내기 및 마케팅 문구

기본은 **캡컷에서 직접 내보내기**입니다. 드래프트가 프로젝트 목록에 뜹니다.
자동 내보내기는 부가 기능이며 기본으로 꺼져 있습니다 (아래 미검증 항목 참고).

사전 질문 3문항에 답하면 자막 전문과 합쳐 프롬프트를 만들어 줍니다.
클립보드에 복사하거나 txt로 저장해서 원하는 AI에 붙여넣으세요.

### 5차 세로용 영상

자막 타임라인에서 시작/끝을 고르면 1080x1920 드래프트를 만듭니다.
배경 이미지는 `assets/bg/` 폴더에 넣어 두세요.

> 고르는 시각은 **컷 편집 후(편집본)** 기준인데 실제로 잘라 쓸 소재는 **원본**입니다.
> 그 사이 잘려나간 컷이 있으면 원본에서는 여러 조각이 됩니다.
> 도구가 자동으로 역변환해 쪼갭니다. "원본 구간 미리 확인" 버튼으로 몇 조각이 되는지 볼 수 있습니다.

## 4. 안전장치

- **캡컷이 실행 중이면 드래프트를 쓰는 모든 작업이 차단됩니다.**
  캡컷은 프로젝트를 메모리에 들고 있다가 저장할 때 파일을 통째로 덮어씁니다.
  켜진 상태로 고치면 작업이 사라집니다. 작업 직후에도 다시 검사해서 그 사이 캡컷이 켜졌으면 경고합니다.
- 드래프트를 고치기 전에 항상 `backups/` 에 스냅샷을 남깁니다. 되돌리기 버튼이 있습니다.
- **드래프트를 다시 만들 때도 기존 것을 먼저 백업합니다.** 같은 이름으로 다시 만들면
  폴더가 통째로 지워지기 때문에, 자막까지 넣어 둔 작업이 사라지지 않게 스냅샷을 남깁니다.
- 같은 작업을 두 번 눌러도 하나만 돕니다. 두 번째 요청은 진행 중인 작업에 다시 연결됩니다.
- 취소하면 하위 프로세스까지 종료하고 부분 파일을 정리합니다.
- 자막을 넣은 뒤 **파일을 다시 읽어** 확인합니다. 화면에는 요청한 개수가 아니라
  **실제로 확인된 개수**가 표시됩니다.
- `logs/` 에 날짜별 로그가 쌓입니다. 화면 오른쪽 아래 "로그" 버튼으로도 볼 수 있습니다.

> **이미 캡컷에 열어 둔 프로젝트는 완전히 종료했다가 다시 열어야 반영됩니다.**

## 5. 미검증 항목

개발과 검증은 Linux 컨테이너에서 했습니다. 아래는 **Windows 실기에서 확인이 필요합니다.**
정직하게 적어 둡니다.

| 항목 | 상태 | 이유 |
|---|---|---|
| 캡컷에서 결과 열어 육안 확인 | **미검증** | 캡컷이 Windows 전용이라 이 환경에 없음 |
| 드래프트 폴더 자동 탐지의 실제 경로 | **미검증** | `%LOCALAPPDATA%`가 없음. 탐지 로직과 제외 규칙만 테스트 |
| `root_meta_info.json` 등록 후 캡컷 목록 노출 | **미검증** | 실제 캡컷 필요. 파일 갱신 자체는 테스트로 확인 |
| 캡컷 프로세스 감지 | **미검증** | 실제 캡컷 프로세스가 없음. 이름 매칭 로직만 확인 |
| **음성 인식 (faster-whisper)** | **미검증** | 이 환경에서 huggingface.co가 막혀 모델을 못 받음. 아래 참고 |
| 자동 내보내기 | **미검증** | `uiautomation` 필요(Windows 전용). **기본 OFF** |
| bat 파일 실제 실행 | **부분검증** | CP949 인코딩·chcp 부재·CRLF는 테스트로 확인. cmd 실행은 미검증 |
| 한글 경로 깨짐 방어 | **부분검증** | 3중 방어 구현 + 감지 로직 테스트. 실기 재현은 미검증 |

### 음성 인식에 대해

코드는 다 있지만 **이 환경에서 모델을 내려받아 실제로 돌려 보지 못했습니다.**
처음 실행하면 모델을 받습니다 (medium 약 1.5GB). 도구가 누르기 전에 미리 알려 주고
받는 동안 진행률을 보여 줍니다.

- 기본 모델은 `large-v3`가 아니라 **`medium`** 입니다. GPU가 없으면 CPU로 도는데
  large-v3는 훨씬 느립니다.
- NVIDIA GPU가 없으면 CPU로 돕니다. Intel Arc는 CTranslate2가 지원하지 않습니다.
- 긴 영상은 10분씩 나눠 처리하고 각 조각의 결과를 디스크에 남깁니다.
  중간에 취소하거나 실패해도 다시 실행하면 끝난 조각은 건너뜁니다.
- 진행률이 한동안 0으로 보이면 `huggingface_hub`가 staging 폴더에 먼저 받는 중일 수 있습니다.
  도구는 `~/.cache/huggingface/xet` 도 함께 세지만, 그래도 느리게 보일 수 있습니다.

**첫 실행은 여유 있게 잡으세요.**

### 검증한 것

| 항목 | 방법 |
|---|---|
| pyCapCut 실물 API | `pycapcut==0.0.3` 설치 후 소스 열람 + 실제 드래프트 생성 |
| 드래프트 생성·자막 주입 | 가짜 드래프트 루트에 실제로 만들고 JSON 필드 확인 |
| 레이어·비율·메타·레지스트리 교정 | 생성 결과를 다시 읽어 확인 |
| ffmpeg stderr 데드락 방어 | 배출량 실측 (아래 참고) |
| 오디오 추출·무음 감지 | 설계값을 넣은 wav로 감지 정확도 확인 |
| 자막 규칙·컷 매핑·서명 비교 | 단위 테스트 160개 |
| 서버 기동과 0~5차 API | 실제 HTTP로 전 구간 (음성 인식만 합성 데이터) |

테스트 돌리기:

```
python -m unittest discover -s tests -t .
```

## 6. 알려진 제약

- 캡컷은 공식 자동화 API를 제공하지 않습니다. pyCapCut은 드래프트 JSON 구조를
  리버스 엔지니어링한 **비공식 도구**이며, 캡컷 업데이트로 언제든 깨질 수 있습니다.
- pyCapCut은 베타 단계입니다. 애니메이션·효과·트랜지션이 의도대로 적용되지 않는
  사례가 보고돼 있으므로 **적용 후 캡컷에서 육안 확인이 필요합니다.**
- 자동 내보내기는 Windows 전용이고 캡컷 버전·UI 언어에 민감합니다. 한국어 UI에서
  동작할지 확인하지 못했습니다. **이 기능만 캡컷이 실행 중이어야 합니다** (다른 모든 단계와 반대).
- 필러워드와 말더듬 자동 감지는 완벽할 수 없습니다. **검수 UI가 이 도구의 핵심입니다.**
- 음성 인식은 오타를 냅니다 (캡컷 → "캡커스", 컷 → "컵"). 용어 사전과 검수로 보완하세요.
- 트랜지션 이름은 대부분 중국어라 한국어 UI 이름과 매칭되지 않습니다. `effect_id`로만 찾습니다.
- 검증한 캡컷 버전은 9.3.0.3969(beta)입니다. 다른 버전에서는 결과가 다를 수 있습니다.

## 7. 문제가 생기면

증상과 원인이 멀리 떨어져 있는 경우가 많습니다. 자주 나오는 것들:

| 증상 | 원인 | 어떻게 |
|---|---|---|
| 진행률이 2%에서 멈춤 | ffmpeg stderr 파이프가 막힘 | 도구가 3중으로 막고 있습니다. 그래도 나면 로그를 확인하세요 |
| 자막이 파일엔 있는데 화면에 안 보임 | 자막과 영상이 같은 레이어 | 저장 후 자동 교정 + 검사합니다 |
| 흰 배경이 안 나옴 | 배경 비트가 빠짐 | 캘리브레이션을 다시 하세요 |
| 자막 글꼴이 기본 글꼴로 바뀜 | 폰트 절대경로가 비었거나 파일이 없음 | 캘리브레이션 화면에서 글꼴을 직접 고르세요 |
| 경로에 `????` 가 보임 | 하위 프로세스 인코딩 | 앱 내장 찾아보기나 직접 붙여넣기를 쓰세요 |
| bat을 더블클릭하면 창만 깜빡 | bat 파일을 UTF-8로 다시 저장함 | **bat 파일을 편집·재저장하지 마세요.** CP949로 저장돼 있어야 합니다 |
| 말끝이 잘려 들림 | 말 끝난 뒤 여유가 짧음 | 1차에서 그 값을 0.35초 이상으로 |
| 자막 싱크가 안 맞음 (뒤로 갈수록 벌어짐) | 드래프트와 컷 설정 불일치 | 도구가 차단합니다. 드래프트를 다시 만드세요 |
| 캡컷에 바꾼 내용이 안 보임 | 캡컷이 이미 열고 있던 프로젝트 | 캡컷을 완전히 종료했다가 다시 여세요 |

그래도 모르겠으면 `logs/` 폴더의 오늘 날짜 파일을 확인하세요.
