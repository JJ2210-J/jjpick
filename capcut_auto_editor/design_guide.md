# design_guide.md — UI 디자인 토큰

> ⚠ **이 파일은 임시본입니다.**
> 요청서 5절은 이 가이드를 "별도 제공"이라고 했는데 전달받지 못해,
> 요청서에 적힌 톤("전문적이되 딱딱하지 않게", "이모지는 단계 아이콘 정도로만")에
> 맞춰 최소 토큰 세트를 임시로 정의했습니다.
> **실제 가이드를 받으면 이 파일의 값만 교체하면 됩니다** —
> `static/styles.css`는 전부 아래 CSS 변수만 참조하고 하드코딩된 색·간격이 없습니다.

## 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#F7F6F3` | 페이지 배경 |
| `--surface` | `#FFFFFF` | 카드/패널 |
| `--surface-2` | `#F1EFEA` | 보조 배경, 비활성 |
| `--line` | `#E3E0D9` | 경계선 |
| `--text` | `#2B2926` | 본문 |
| `--text-sub` | `#7A756C` | 보조 텍스트 |
| `--brand` | `#3B6EA5` | 주 강조, 활성 단계 |
| `--brand-weak` | `#E8EFF7` | 주 강조 배경 |
| `--ok` | `#2E7D57` | 완료 |
| `--warn` | `#B4761E` | 경고 |
| `--danger` | `#B4453A` | 차단/실패 |
| `--danger-weak` | `#FBECEA` | 차단 배경 |

## 타이포

- 글꼴: `'Pretendard', 'Apple SD Gothic Neo', 'Malgun Gothic', system-ui, sans-serif`
- `--fs-xs` 12px / `--fs-sm` 13px / `--fs-md` 14px / `--fs-lg` 16px / `--fs-xl` 20px
- 굵기: 본문 400, 강조 600, 제목 700

## 간격 · 반경

- `--sp-1` 4px / `--sp-2` 8px / `--sp-3` 12px / `--sp-4` 16px / `--sp-5` 24px / `--sp-6` 32px
- `--radius` 10px / `--radius-sm` 6px
- `--shadow` `0 1px 3px rgba(0,0,0,.06)`

## 레이아웃

- 좌측 단계 네비게이션 고정 폭 `--nav-w` 240px, 우측 작업 영역 가변
- 작업 영역 최대 폭 `--content-max` 900px

## 상태 표기

| 상태 | 색 | 표기 |
|---|---|---|
| 완료 | `--ok` | 체크 |
| 진행중 | `--brand` | 스피너 |
| 잠김(선행 미완) | `--text-sub` | 흐리게 + 이유 문구 필수 |
| 차단(안전장치) | `--danger` | 배경 `--danger-weak` + 해결 방법 문구 필수 |

## 원칙

1. 여기 없는 값을 임의로 만들지 않습니다. 필요하면 이 파일에 먼저 추가합니다.
2. 이모지는 좌측 단계 아이콘에만 씁니다. 본문·버튼에는 쓰지 않습니다.
3. 모든 실패 표시는 **무엇이 / 왜 / 어떻게 하면 되는지** 세 가지를 반드시 포함합니다.
